## Sobre o projeto:
Este projeto é um **Classificador de Consumo de Água**, desenvolvido em **Python** 🐍💧.
O programa solicita o **tipo de imóvel e o consumo mensal de água em m³**, classificando o consumo de acordo com as regras definidas para cada tipo de imóvel.

## Objetivo:
Esse projeto é um trabalho que fiz para meu curso, como forma de aprendizado da linguagem Python e do uso do Git e do GitHub.

## Classificação do consumo:

- 🏢 **Imóvel comercial:** tarifa comercial aplicada.
- 💧 **Apartamento com consumo menor que 10 m³:** consumo econômico.
- 🏠 **Apartamento ou casa com consumo de até 25 m³:** consumo moderado.
- ⚠️ **Demais casos:** consumo excessivo.

## Como executar:

### 1. Instale o Python
É necessário ter o **Python 3** instalado em seu computador para executar o programa.

### 2. Abra a pasta do projeto
Abra o terminal na pasta **"consumo-agua"**, onde estão os arquivos `app.py` e `README.md`.

### 3. Execute o programa
No terminal, utilize o comando:

```text```
python app.py

Após executar o comando, o programa solicitará o tipo do imóvel e o consumo em metros cúbicos.
